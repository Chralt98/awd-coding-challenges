Welcome to the Burn-on-read service!

This service allows you to create messages that will be automatically deleted after being read once. Perfect for sharing sensitive information securely.

To create a burn-on-read message, simply send a POST request to /messages with the message content in the request body. You will receive a unique URL that you can share with the intended recipient.

Once the recipient accesses the URL, the message will be displayed and then immediately deleted from our servers, ensuring that it cannot be accessed again.
