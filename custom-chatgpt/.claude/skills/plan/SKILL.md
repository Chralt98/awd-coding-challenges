description: Use the produced output (at `plan/<feature>-refinement.md`) from the refine skill and write a test-driven development plan for the user feature.
---

1. Identify the feature's kebab-case slug (matching the `plan/<feature>-refinement.md` file produced by the refine skill) and use it in place of `<feature>` below.
2. Read the report at `plan/<feature>-refinement.md` and identify the key components and interactions that need to be tested.
3. For each component, write a set of test cases that cover the expected behavior, edge cases, and error handling.
4. Organize the test cases into a structured test plan located at `plan/<feature>-plan.md`.
