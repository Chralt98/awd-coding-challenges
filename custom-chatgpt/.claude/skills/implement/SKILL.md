---
name: implement
description: Implement a user feature based on the test-driven development plan produced by the `plan` skill.
---

1. Identify the feature's kebab-case slug (matching the `plan/<feature>-plan.md` file produced by the plan skill) and use it in place of `<feature>` below.
2. Read the test plan at `plan/<feature>-plan.md` and identify the components and interactions that need to be implemented.
3. For each component, write the necessary code to implement the expected behavior, edge cases, and error handling as specified in the test plan.
4. Run the tests to ensure that the implementation passes all test cases. If any tests fail, debug and fix the implementation until all tests pass.
