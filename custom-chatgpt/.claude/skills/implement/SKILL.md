---
name: implement
description: Implement a user feature based on the test-driven development plan produced by the `plan` skill.
---

1. Read the test plan at `plan/feature-x-plan.md` and identify the components and interactions that need to be implemented.
2. For each component, write the necessary code to implement the expected behavior, edge cases, and error handling as specified in the test plan.
3. Run the tests to ensure that the implementation passes all test cases. If any tests fail, debug and fix the implementation until all tests pass.
